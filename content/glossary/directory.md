# Directory

A **directory** is a container used to organize files.

Directories can also contain other directories.

Think of them like folders inside a filing cabinet.

## Example

```
/
├── home
│   ├── notes.txt
│   └── projects
```

Here:

- `/` is a directory.
- `home` is a directory.
- `projects` is a directory.
- `notes.txt` is a file.
