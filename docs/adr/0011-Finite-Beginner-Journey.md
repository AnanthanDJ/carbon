# ADR-0011: Finite Beginner Journey

**Status:** Accepted

## Context

The platform is intended to reduce fear, not become a lifelong learning platform.

## Decision

The beginner curriculum ends with a clear graduation point.

After completion, optional exploration modules become available.

The project measures success by users confidently transitioning to a real terminal.

## Consequences

### Advantages

- Clear educational goal
- Avoids endless tutorials
- Reinforces project philosophy

### Trade-offs

- Smaller initial content library
