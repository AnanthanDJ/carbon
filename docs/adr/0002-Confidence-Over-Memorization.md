# ADR-0002: Confidence Over Memorization

**Status:** Accepted

## Context

A beginner survey revealed common issues:

- Fear of terminals
- Memorizing commands without understanding
- Lack of awareness of documentation
- Dependence on tutorials

The project exists to address these observations.

## Decision

The platform will optimize for **confidence-building** rather than command memorization.

Lessons must encourage:

- Experimentation
- Reading documentation
- Understanding command purpose

Rather than copying commands.

Hints must progressively guide users instead of immediately revealing answers.

## Consequences

### Advantages

- Builds independent learners
- Aligns with project philosophy

### Trade-offs

- Slightly slower initial progression
- More lesson design effort
