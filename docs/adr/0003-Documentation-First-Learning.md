# ADR-0003: Documentation-First Learning

**Status:** Accepted

## Context

Most beginners interviewed were unaware that documentation existed or did not know how to use it.

## Decision

Every lesson must integrate documentation directly into the learning experience.

Documentation is considered part of the lesson rather than external reference material.

The platform should bridge users toward official documentation instead of replacing it.

## Consequences

### Advantages

- Establishes good habits
- Reduces dependence on tutorials

### Trade-offs

- Documentation must be carefully simplified without becoming inaccurate
