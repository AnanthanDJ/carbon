# ADR-0012: Product Philosophy

**Status:** Accepted

## Context

Most educational products optimize for user retention.

This project has a different objective.

## Decision

Carbon is a stepping stone.

It exists to prepare users for real terminals.

The project is considered successful when users no longer need it.

## Consequences

This principle should guide all future design decisions.

Features that reduce independence should be rejected.

Features that increase confidence should be prioritized.
