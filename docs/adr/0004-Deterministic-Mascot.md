# ADR-0004: Deterministic Mascot

**Status:** Accepted

## Context

Modern educational platforms frequently use AI assistants.

However, the project's objective is to build independent learners rather than create answer dependency.

## Decision

The mascot ("Mux") will be **deterministic**.

Mux will:

- Explain terminology
- Provide progressive hints
- Encourage experimentation
- Celebrate progress

Mux will not:

- Generate arbitrary answers
- Solve challenges immediately
- Invent explanations

## Consequences

### Advantages

- Predictable educational experience
- Consistent quality
- Aligns with project philosophy

### Trade-offs

- Larger content authoring effort
- No free-form conversations
